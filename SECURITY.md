# Security Policy

## Supported Versions

Only the latest release gets security fixes.
Pin the action to the latest release, or to its commit SHA, to get them.

## Reporting a Vulnerability

Please do not report vulnerabilities in public issues.
Report them privately through
[GitHub's private vulnerability reporting](https://github.com/CallumKerson/test-reports-action/security/advisories/new).

You can expect a reply within a week.
If the report is accepted, a fix will be released and a security advisory
published, crediting you unless you would rather not be named.
If it is declined, you will get an explanation of why.
